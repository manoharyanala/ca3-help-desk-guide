# Helpdesk Contact Update

This repository addresses a known issue where outdated contact information was being provided to students, leading them to an incorrect helpdesk contact page.

## Issue
Students were being directed to a legacy/old contact page for helpdesk support.

## Solution
This update redirects the documentation and links to the correct, active helpdesk support channel.

## Changes
- Updated incorrect URL/contact reference in the helpdesk introduction/guide.
- Verified the new link directs to the current support platform.

## Verification
